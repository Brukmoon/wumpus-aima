Chapter 15 · Probabilistic Programming

The code that generates random Wumpus worlds is already a probabilistic model. Write it as a probabilistic program, observe the percepts, and a generic inference engine returns a posterior over entire worlds. No Bayes-net diagram is needed. Swapping in a different program, such as an open-universe model where even the number of pits is unknown, needs no change to the inference code.
