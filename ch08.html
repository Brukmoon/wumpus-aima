Chapter 8 · First-Order Logic

Propositional logic needs one symbol per square: P1,2, P2,1, … First-order logic talks about objects (squares, the agent, the wumpus), relations (Pit, Adjacent, At) and functions (Home). With quantifiers, one sentence covers every square: ∀s Breezy(s) ⇔ ∃r Adjacent(r, s) ∧ Pit(r). Below, the current world is the model. Type a sentence and see whether it is true in it, and why.

Interpretation what each symbol refers to in this model

Is this sentence true in the model?

Write ∀ ∃ ¬ ∧ ∨ ⇒ ⇔ (or forall, exists, ~, &, |, =>, <=>). Variables are lowercase and constants Capitalized. Squares are written [x,y]. Variables x, y, a, b, i, j range over the numbers 1…n; every other variable ranges over the squares.

One FOL sentence = many propositional sentences

Grounding replaces each universally quantified variable by every object. Then Adjacent is evaluated and the ∃ is simplified. The results are exactly the propositional sentences Chapter 7 had to write out one by one.

Chapter notes & questions
  1. Evaluate ∀s Breezy(s) ⇔ ∃r Adjacent(r, s) ∧ Pit(r). Then use Edit world to add a pit. It stays true, because it is an axiom that holds in every Wumpus world. Now find a sentence that is true in this world but not in others. That is a fact, not an axiom.
  2. Write “there is exactly one wumpus” in FOL.
    hint∃s At(Wumpus, s) ∧ ∀r At(Wumpus, r) ⇒ r = s
  3. Why is ∀s Pit(s) ∧ Adjacent(s, [1,1]) almost certainly false, and what did the writer probably mean? (§8.2.6: ∀ goes with ⇒, ∃ goes with ∧.)
  4. Try the “common mistake” example ∃s Pit(s) ⇒ Adjacent(s, [4,4]). Why is it true in almost every world?
  5. How does Home(Wumpus) = [1,3] differ from At(Wumpus, [1,3])? Which one lets you write Adjacent(Home(Wumpus), s)?
