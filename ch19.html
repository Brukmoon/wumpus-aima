Chapter 19 · Learning from Examples

So far a human wrote down how breezes relate to pits. Can an agent learn it from experience? We play many random caves with the safe-exploration agent. Every square left on the frontier becomes a labelled example: a few features describing what was perceived around it, and whether a pit was really there. Then a decision tree is learned from the examples.

Chapter notes & questions
  1. Which attribute does the tree test first, and why does it have the highest information gain?
  2. The tree can't beat the Bayes-optimal classifier (predict “pit” when the exact posterior exceeds 0.5). Why is that the ceiling for any learner using this information?
  3. Watch the overfitting chart. With very few training worlds, which depth is best? And with many?
  4. Find the branch that encodes “a breezy neighbour whose only possible culprit is this square”. That is a rule Chapter 7 derived by logic, and the tree has learned it from data.
  5. Logistic regression uses the same features but a linear model. Where does it lose to the tree, and why?
    hint“calm neighbour ⇒ no pit, whatever else” is an interaction that a linear model over one-hot features can only approximate.
