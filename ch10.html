Chapter 10 · Knowledge Representation

What should an agent's knowledge be about? This chapter covers categories of objects, events and time, reasoning with defaults that may have to be retracted, and knowledge about knowledge. Each gets a lab in the Wumpus World.

Chapter notes & questions
  1. Ontology. Deadly is inherited by Pit and by Wumpus from Hazard. Why is “a dead wumpus is not deadly” awkward to state in plain FOL, and natural as a default with an exception (§10.6)?
  2. Events. Count the frame axioms a naive axiomatization would need for this grid, and compare with the number of successor-state axioms. Which fluents change most often?
  3. Events. At some time t, pick a fluent that holds and explain it with the event-calculus axiom: which event Initiated it, and why wasn't it Clipped since?
  4. Defaults. Follow the TMS agent. Each retraction happens because a new percept made some square suspicious. Find a step where one percept retracts several assumptions at once.
  5. Defaults. The agent plans through assumed-safe squares but only steps onto proved-safe ones. What would change if it trusted its defaults when acting?
  6. Knowledge. Find a square where the truth is “pit” but the agent neither knows it nor knows its negation. How many possible worlds is it considering?
